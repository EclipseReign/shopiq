# Участие в разработке

Опишите проблему или предложение в Issues. Для исправления создайте отдельную ветку и pull request с описанием поведения до и после изменения.

Перед отправкой выполните проверки.

```sh
npm ci
npm test
npm run build
npm run typecheck --workspace cloud
npm audit --omit=dev
```

Изменения схемы оформляются новой миграцией в `supabase/migrations`. Для изменения парсинга добавьте обезличенный пример ответа и проверьте пагинацию, количество уникальных товаров и сохранение предыдущих наблюдений. Для правил цен проверьте округление, границы, устаревшие расчёты и сохранение остальных SKU и городов в XML.

Пароли, серверные ключи, JWT, секретные ссылки прайсов и XML действующих магазинов не должны попадать в коммиты, скриншоты и публичные Issues. Для уязвимостей используйте приватный канал из [SECURITY.md](SECURITY.md).
