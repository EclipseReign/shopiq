# Безопасность

Сообщения об уязвимостях можно направить через приватный канал репозитория. В отчёте достаточно шагов воспроизведения, затронутого маршрута и обезличенных примеров. [Сообщить об уязвимости](https://github.com/EclipseReign/shopiq/security/advisories/new)

## Реализованные меры

- Supabase Auth проверяет пользователя на сервере, подтверждение email обязательно. Администратор определяется по проверенному адресу серверной конфигурации.
- RLS и права PostgreSQL ограничивают личные данные владельцем. Привилегированные SQL-функции доступны серверной роли.
- Серверные ключи хранятся в Cloudflare Secrets. В клиент передаётся publishable key.
- Личные ответы имеют `no-store`, общие данные кешируются отдельно. CSP, запрет встраивания, `nosniff` и HSTS устанавливаются для веб-приложения.
- Мутации проверяют Origin и Bearer-токен, публичные запросы ограничиваются по частоте.
- Сбор обращается к фиксированным маршрутам Kaspi. Внешние URL импорта отсутствуют, XML передаётся файлом.
- XML ограничен по размеру и сложности. DTD и сущности отклоняются. Выгрузка имеет отдельную ограничительную CSP.
- Публикация цен транзакционна, проверяет владельца, срок расчёта, версии и ограничения. Ссылки прайсов имеют случайные токены, в базе сохраняются хеши.

## Проверки

Автоматические тесты покрывают изоляцию владельцев, изменение владельца строки, доступ к привилегированным RPC, XXE, сохранение полного XML, минимальную маржу, устаревшие расчёты, конфликтующие подтверждения и повторную обработку страниц. Живые проверки облачной версии включают два тестовых аккаунта, ручную и автоматическую публикацию XML и выполнение очереди.

## Известные вопросы

В старой истории Git присутствовали реквизиты Railway PostgreSQL из прежней версии проекта. Они удалены из текущих файлов. Для закрытия старого доступа требуется перевыпуск пароля в Railway. Серверные ключи новой облачной версии созданы отдельно.

`npm audit --omit=dev` проверяет production-зависимости. В полном аудите остаётся известная уязвимость `picomatch` через инструменты Vite. На момент проверки исправленной версии upstream нет. Используются фиксированные шаблоны конфигурации сборки. [GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf)

Проверка Supabase также отмечает выключенную защиту от паролей из утечек. Эта функция доступна на тарифе Pro и выше. Для текущего проекта установлен минимум 12 символов, переход на платный тариф не выполнялся. [Безопасность паролей Supabase](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection)

Доступ к рабочему магазину, результат загрузки прайса в Kaspi и бизнес-ограничения цены проверяются владельцем при подключении своего XML. [Подключение прайса Kaspi](https://guide.kaspi.kz/partner/ru/shop/goods/price_list/q3251)
